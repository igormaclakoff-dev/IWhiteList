# 🛡️ IWhiteList

**Удобный белый список от студии AuraCode** — открытый плагин для Paper 1.21.x.

Полноценная замена ванильного вайтлиста: GUI-управление, временные записи, уведомления персоналу и интеграция с PlaceholderAPI.

## ✨ Возможности

- **Полный контроль над входом** — плагин сам решает, кого пускать на сервер, и заменяет ванильный вайтлист.
- **GUI-управление** — красивый инвентарь с головами игроков, пагинацией, добавлением и удалением прямо из меню.
- **Временные записи** — `/iwl add <игрок> 7d`: игрок вылетает из списка автоматически по истечении срока.
- **Своё сообщение при кике** — текст отказа настраивается в `config.yml` (MiniMessage, многострочный).
- **Уведомления персоналу** — онлайн-админы узнают о попытках входа не из списка и об истечении временных записей.
- **Быстрый переключатель** — команда `/iwl on|off` и кнопка в GUI мгновенно включают/выключают вайтлист.
- **Обход для администрации** — право `iwhitelist.bypass` пропускает игрока всегда.
- **Логи действий** — все добавления, удаления и переключения пишутся в `actions.log`.
- **Отслеживание смены ника** — имена в списке автоматически обновляются при входе игрока.
- **PlaceholderAPI** — плейсхолдеры `%iwhitelist_*%` для табло, чатов и меню.
- **Хранение по UUID** — записи не ломаются при смене ника, данные в `whitelist.yml`.

## 🎮 Команды

| Команда | Описание | Право |
|---|---|---|
| `/iwl` | Открыть GUI белого списка | `iwhitelist.command.menu` |
| `/iwl help` | Справка по командам | `iwhitelist.command.help` |
| `/iwl list [стр.]` | Список игроков в чате | `iwhitelist.command.list` |
| `/iwl add <игрок> [срок]` | Добавить игрока (срок: `1h`, `7d`, `permanent`) | `iwhitelist.command.add` |
| `/iwl remove <игрок>` | Удалить игрока из списка | `iwhitelist.command.remove` |
| `/iwl info <игрок>` | Информация о записи | `iwhitelist.command.info` |
| `/iwl on` / `/iwl off` | Включить / выключить вайтлист | `iwhitelist.command.toggle` |
| `/iwl reload` | Перезагрузить конфигурацию | `iwhitelist.command.reload` |

**Алиасы:** `/iwhitelist`.

> Все команды поддерживают **Tab-дополнение** (подкоманды, ники онлайн-игроков, сроки).

В GUI доступны: кнопка **добавления** (ввод ника в чат), **переключение** вайтлиста, листание страниц и **удаление** записи с подтверждением.

## 📦 Установка

1. Скачайте `IWhiteList-1.0.0.jar` (см. раздел «Сборка» или Releases).
2. Положите jar в папку `plugins/` вашего Paper-сервера.
3. Перезапустите сервер — плагин создаст `plugins/IWhiteList/config.yml`, `messages.yml` и `whitelist.yml`.
4. Настройте `config.yml` и сообщения в `messages.yml`.

> Плагин сам отключает ванильный вайтлист (`settings.disable-vanilla-whitelist`), чтобы полностью управлять входом на сервер.

**Требования:** Paper 1.21.x, Java 21+.
**Мягкая зависимость:** PlaceholderAPI (для плейсхолдеров).

## ⚙️ Конфигурация (`config.yml`)

```yaml
whitelist:
  # Главный переключатель. Если выключен — вход разрешён всем.
  # По умолчанию выключен, чтобы пустой список не заблокировал сервер:
  # сначала добавь игроков, затем включи через /iwl on.
  enabled: false
  # Сообщение игроку не из списка (MiniMessage). Поддерживает <player>.
  kick-message: |-
    <gradient:#7B2FF7:#00D4FF><bold>IWhiteList</bold></gradient>
    <red>Тебя нет в белом списке.
  # Кикнуть игрока сразу после истечения его временной записи.
  kick-on-expiry: true

settings:
  # Отключить ванильный вайтлист на старте, чтобы управлять доступом самостоятельно.
  disable-vanilla-whitelist: true
  # Уведомлять персонал (право iwhitelist.notify) об отказах входа и истечении записей.
  notify-admins: true
  # Писать все изменения в plugins/IWhiteList/actions.log.
  log-actions: true
  # Как часто (в секундах) проверять и удалять истёкшие временные записи.
  expiry-check-seconds: 30
```

Все текстовые сообщения находятся в `messages.yml` и поддерживают **MiniMessage** (градиенты, HEX, `<bold>` и т.д.).

## 🧩 PlaceholderAPI

| Плейсхолдер | Описание |
|---|---|
| `%iwhitelist_enabled%` | Состояние вайтлиста (включён/выключен) |
| `%iwhitelist_count%` | Количество игроков в списке |
| `%iwhitelist_status%` | Находится ли игрок в списке |
| `%iwhitelist_expires%` | Оставшийся срок или «навсегда» |

## 🧭 Как это работает

1. Игрок заходит на сервер — плагин проверяет, есть ли его UUID в белом списке.
2. Если вайтлист включён и игрока нет в списке (и нет права `iwhitelist.bypass`) — вход отклоняется с настраиваемым сообщением, а персонал получает уведомление.
3. Администратор добавляет игрока командой `/iwl add` или через GUI; можно указать срок действия.
4. Временные записи автоматически удаляются по истечении срока (при необходимости игрок кикается).
5. При входе игрока его ник в списке актуализируется.
